## 🚀 Deployment Methods

### Option 1: GitHub Pages (Recommended)
**Free hosting, custom domain support, automatic updates**

1. Create GitHub repo
2. Push code: `git push`
3. Enable Pages in Settings
4. Live in 2 minutes at `username.github.io`

### Option 2: Netlify
**Alternative with drag-and-drop deployment**

1. Zip the template folder
2. Drag to Netlify
3. Live instantly

### Option 3: Custom Hosting
Upload via FTP to any web host

## 🎨 Image Specifications

### Required Images Per Project
- **Thumbnail** (homepage grid): 1200×900px, ~150 KB
- **Hero** (project page top): 2000×1200px, ~400 KB
- **Content images** (plans, sections, etc.): Variable, 1600-2000px wide

### Optimization Tools
- [TinyPNG.com](https://tinypng.com/)
- [Squoosh.app](https://squoosh.app/)
- Photoshop "Export for Web"

**Target**: 100-500 KB per image for fast loading
